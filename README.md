# 🌦️ Weather App

A modern and responsive Weather App built using **HTML**, **CSS**, and **JavaScript**. It provides real-time weather information for any city using a weather API, featuring a clean user interface and a smooth user experience.

---

## 📖 Overview

The Weather App allows users to search for any city and instantly view current weather conditions such as:

- 🌡️ Temperature
- ☁️ Weather Condition
- 💧 Humidity
- 🌬️ Wind Speed
- 📍 Location
- 🕒 Local Time (if supported by the API)

Designed with a responsive layout, the application works seamlessly across desktop, tablet, and mobile devices.

---

## ✨ Features

- 🔍 Search weather by city name
- 🌍 Real-time weather updates
